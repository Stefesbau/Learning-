# Nayla – Lernen mit Lumi

Lern-App für Nayla. Material fotografieren oder eintippen, Lumi macht daraus Lernzettel, Karteikarten, Quiz und einen Lernplan bis zur Klausur.

**App öffnen:** https://stefesbau.github.io/Learning-/
Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Stand

- Version 0.1 – Grundgerüst: Start, Bibliothek mit Fächern, Material hinzufügen (Foto, Link, Text), Kalender mit Klausuren, Profil mit Serie/XP/Level, Helferin Lumi.
- Daten liegen vorerst nur im Browser des Geräts.
- Als Nächstes: Anmeldung und Datenbank (Supabase), dann KI (Claude) für Lernzettel, Karteikarten, Quiz, Lernplan und Tutor.

## Technik

React + Vite + TypeScript, veröffentlicht über GitHub Pages (`.github/workflows/deploy.yml`).

```bash
npm install
npm run dev
```
